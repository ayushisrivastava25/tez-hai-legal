## Hosting

GitHub Pages serves the prebuilt files from **main / (root)**. The `.nojekyll` file disables Jekyll processing. No npm installation or custom deployment workflow is needed.

This information site contains no playable game, login, tracking scripts, analytics SDKs or forms. Support and deletion links open an email draft; sending a request does not itself erase an account. GitHub may process hosting/security request data under its own policies.
